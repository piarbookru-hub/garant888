# 🛡️ Бизнес-поддержка — Легальное снижение НДС для компаний

Современный адаптивный сайт-визитка для компании, предоставляющей услуги легальной оптимизации НДС и подготовки кассовых чеков с QR-кодом для отчётности.

---

## 📋 Описание проекта

Сайт перенесён с платформы **Tilda** на чистый HTML/CSS/JS с сохранением всей структуры, дизайна и функциональности. Работает автономно, без зависимости от внешних конструкторов.

### 🎯 Основные услуги, представленные на сайте:
- **Легальное снижение НДС** — уменьшение налога без рисков и посредников
- **Кассовые чеки с QR-кодом** — настоящие чеки с проверкой через сайт ФНС
- **Поддержка до 3 лет** — сопровождение после оказания услуг
- **Работа во всех регионах** — полностью удалённо
